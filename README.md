# 腎囊醫訣（Bodleian Sinica 1845）v0.2.1

曲宸宇（Chen-Yu Chu）。1874 年《腎囊醫訣》轉錄的訂正附檔。
包含 7 處回圖修訂，以及第八批 13 個問題群組的判定。
各項記錄轉錄單元、原讀、修訂與原圖定位；[訂正表](CORRECTIONS.md) 可直接閱讀。
已核定的數值與字形依原印處理。無法判明及跨頁用字抽核的結果另有標示。

搭配 [v0.2.0 固定底版](https://github.com/poplolioi11/bodleian-sinica1845-shennang-yijue-1874/releases/tag/v0.2.0) 或
[Zenodo v0.2.0](https://doi.org/10.5281/zenodo.24149581) 使用。
`ERRATA.json` 提供修改操作。先核對底版 `document.json` 的 SHA-256，
再依 `unit_id` 定位 `units[].id`，比對 `text[start:end]` 和 `before`，
只有相符時才替換為 `after`。位置由 0 起算，以 Unicode 碼位計，右界不含。
這份附檔提供訂正表與差異資料；底版提供全文、純文字和 TEI。
引用採用這批修訂時，請同時標明底版 DOI 與 v0.2.1 附檔。
