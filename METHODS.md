# 方法與AI角色 / Methods

All 497 assigned source faces were independently reread by AI and then compared with the fixed initial transcription. Differences, note attachment and source layers were resolved by nonblind return to the original source, retaining localized unresolved readings. The fixed final native manuscripts cover 195, 60, 24, 46, 70 and 102 disjoint faces. This integration copies their chosen text strings, stable identifiers, ordering, note fragments, anchors, source marks and diagram text mechanically; it performs no new image reading, lexical normalization, arithmetic restoration of folios, or modern medical interpretation. Source reading used fixed 1000px previews, full-frame context and selected original-region details; the public source locators retain the original preview coordinate system. Units without reliable calibrated bounds retain null bbox. AI assistance used an OpenAI native subscription service; actual model, effort, tokens and cash are unavailable in the execution evidence and remain null. No human full-text double collation, expert review, peer review, measured CER, Schematron or complete critical apparatus is claimed. The private images, crops, complete event histories, prompts and specialized production programs are not distributed; a complete image-to-text rerun is therefore not supplied. Public JSON, TXT, TEI and companion structures support exact public-data reconstruction. The private base=result legacy-import annotation audit concerns this round of mechanical integration and format preservation only; it is not a new reading, independent collation, or the original v0.1.0-to-v0.2.0 adjudication history. Revision traceability instead rests jointly on the six fixed native adjudication manuscripts and their private decision/seal references, together with the complete public version diff and field-by-field replay.
